Chasis de Robot 4WD (4 ruedas)
Un chasis 4WD es la estructura principal del robot. Incluye una base de acrílico resistente, cuatro motores DC y cuatro ruedas, lo que brinda mayor estabilidad, fuerza y equilibrio al desplazarse. Este tipo de chasis permite que el robot tenga mejor tracción y soporte más peso que uno de 2 ruedas.
*Características:*
* Base resistente y ligera.
* Incluye 4 motores DC.
* Mayor estabilidad y potencia.
* Ideal para proyectos de robótica móvil.
Arduino Uno R3
El Arduino Uno R3 es la tarjeta principal que controla todo el funcionamiento del robot. Se encarga de recibir información de los sensores y enviar instrucciones a los motores y módulos conectados.
*Características:*
* Microcontrolador ATmega328P.
* Fácil de programar.
* Compatible con muchos sensores y módulos.
* Alimentación por USB o batería.
Puente H L298N
El módulo L298N permite controlar la dirección y velocidad de los motores del robot. Funciona como intermediario entre el Arduino y los motores, ya que el Arduino no puede alimentar motores directamente.
*Características:*
* Control de motores DC y motores paso a paso.
* Permite avanzar, retroceder y girar.
* Control de velocidad mediante PWM.
* Compatible con proyectos de robótica.
Sensor Ultrasonido HC-SR04
El sensor HC-SR04 permite medir distancias utilizando ondas ultrasónicas. Es usado para detectar obstáculos y evitar choques durante el movimiento del robot.
*Características:*
* Detecta objetos a distancia.
* Alta precisión.
* Fácil conexión con Arduino.
* Ideal para robots autónomos.

Módulo Bluetooth HC-05
El HC-05 permite controlar el robot desde un teléfono celular mediante conexión Bluetooth. Facilita el envío y recepción de datos inalámbricamente.
*Características:*
* Comunicación inalámbrica Bluetooth.
* Compatible con Android.
* Fácil configuración.
* Alcance aproximado de 10 metros.
Servomotor SG90
El servomotor SG90 es un motor pequeño que puede girar en ángulos específicos con gran precisión. En este proyecto se utiliza para mover el sensor ultrasónico hacia los lados.
*Características:*
* Movimiento preciso.
* Rotación de hasta 180°.
* Tamaño compacto.
* Bajo consumo de energía.
Portapilas para Baterías 18650
El portapilas sirve para sostener y conectar las baterías recargables que alimentan el robot de manera segura.
*Características:*
* Espacio para 2 baterías 18650.
* Fácil conexión.
* Diseño compacto.
* Alimentación estable para el proyecto.
Baterías Li-ion 18650
Las baterías 18650 son baterías recargables de ion-litio que proporcionan energía suficiente para mover los motores y alimentar los componentes electrónicos del robot.
*Características:*
* Recargables.
* Mayor duración.
* Buena capacidad energética.
* Ideales para proyectos de robótica.
Kit de Cables Jumper
Los cables jumper permiten conectar los componentes electrónicos entre sí sin necesidad de soldadura. Son esenciales para realizar las conexiones en protoboard y módulos.
*Características:*
* Fácil instalación.
* Diferentes tipos de conexión.
* Reutilizables.
* Ideales para prototipos electrónicos.
